# DropBeat — موزیک‌پلیر قطره‌ای

پروژه شامل PWA قابل انتشار روی GitHub Pages و پروژه Android برای ساخت APK از طریق GitHub Actions است.

## اجرای PWA در GitHub Pages
1. تمام فایل‌های این پوشه را در ریشه یک مخزن GitHub آپلود کنید.
2. به Settings → Pages بروید.
3. در بخش Build and deployment گزینه Deploy from a branch را انتخاب کنید؛ Branch روی `main` و Folder روی `/ (root)` باشد.
4. آدرس `https://USERNAME.github.io/REPOSITORY/` را باز کنید. برای نصب PWA از منوی مرورگر Add to Home screen را بزنید.

## ساخت APK با GitHub Actions
1. این مخزن را در GitHub بسازید و همه فایل‌ها را آپلود کنید.
2. در تب Actions، اجرای workflow با نام **Build DropBeat APK** را فعال/اجرا کنید.
3. فایل APK در بخش Artifacts همان اجرای موفق workflow قرار می‌گیرد.
4. APK را دانلود کنید و روی گوشی نصب کنید. برای نصب، ممکن است لازم باشد اجازه نصب از این منبع را در Android فعال کنید.

## امکانات و محدودیت‌های نسخه پایه
- انتخاب چند فایل صوتی از گوشی، پخش/توقف، قبلی/بعدی و نوار زمان.
- قطره شیشه‌ای با انیمیشن CSS و ویژوالایزر مبتنی بر Web Audio API در مرورگرهای پشتیبان.
- داده‌های آهنگ در سرور آپلود نمی‌شوند؛ فایل‌ها از حافظه انتخاب فایل دستگاه خوانده می‌شوند.
- نسخه اولیه از Android WebView استفاده می‌کند. پشتیبانی انتخاب فایل وابسته به WebView و دستگاه است.
- ویجت واقعی صفحه اصلی، کنترل رسانه در پس‌زمینه و سرویس پخش دائمی در این نسخه پیاده‌سازی نشده‌اند.
